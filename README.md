# Жартастағы жасырын шипа

GitHub Pages-ке арналған статикалық сауалнама сайты.

## Іске қосу

Сайтқа сервер мен `npm start` қажет емес. `index.html` файлын браузерде тікелей
ашуға немесе репозиторийді GitHub Pages арқылы жариялауға болады.

`data/responses.json` файлында жинақталған статистика негізінде толықтырылған
143 сауалнама жауабы сақталған. Нәтижелер бетінде осы көрсеткіштерге сәйкес
диаграммалар мен қорытынды кесте көрсетіледі. Сайт арқылы жаңадан жіберілген
жауаптар браузердің жергілікті сақтау орнында сақталады. GitHub Pages
сервердегі файлдарды өзгерте алмайды; барлық құрылғылардан жаңа жауаптарды
бір жерге жинау үшін Firebase немесе Supabase сияқты сыртқы база қажет.
