# Жартастағы жасырын шипа

GitHub Pages-ке арналған статикалық сауалнама сайты.

## Іске қосу

Сайтқа сервер мен `npm start` қажет емес. `index.html` файлын браузерде тікелей
ашуға немесе репозиторийді GitHub Pages арқылы жариялауға болады.

50 синтетикалық демонстрациялық жауап `data/responses.json` файлында сақталған
және нәтижелер бетінде көрсетіледі. Олар `_demo: true` белгісімен нақты
сауалнама жауаптарынан ажыратылған. Нәтижелер дашборды тек осы демо JSON
деректерін көрсетеді; браузердегі бұрынғы локал жауаптар есепке алынбайды.
GitHub Pages сервердегі JSON файлдарын өзгерте алмайды. Барлық құрылғылардан
жауаптарды бір жерге жинау үшін Firebase немесе Supabase сияқты сыртқы база
қажет.
